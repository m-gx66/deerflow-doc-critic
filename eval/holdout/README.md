# 困难用例 21-25

这些错误需要跨句计算、单位换算或日期推理，不能只靠“数值看起来不对”发现。

| 文件 | 错误点 | 正确结果 |
| --- | --- | --- |
| doc_021.docx | 合计超支写成 20% | (141-130)/130 ≈ 8.46%，不是 20% |
